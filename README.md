## 👋 Olá, eu sou o Thiago Vale

Engenheiro de Dados com +5 anos de experiência no desenvolvimento de soluções escaláveis em dados.  
Atuo com foco em **Data Engineering**, **Machine Learning** e **plataformas modernas de dados**, construindo pipelines robustos e arquiteturas orientadas a dados na cloud.

Tenho experiência no processamento de grandes volumes de dados, integração de múltiplas fontes (SQL, NoSQL, APIs e Web Scraping) e na criação de soluções que suportam tomada de decisão estratégica.
